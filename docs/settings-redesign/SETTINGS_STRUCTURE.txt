0) WHY DOES SETTINGS SHOW ANOTHER SETTINGS-LIKE PAGE?

There is only ONE Settings screen. It has two view states inside the same screen:
  1. Index view: header "Settings" + the category cards (Listening / Library & connections / App).
  2. Category view: same screen, body swapped; the header title becomes Playback, Now Playing,
     Appearance, Library, Downloads, Connections, System or About. No second screen, activity
     or navigation destination is pushed.

The index exists because the app has 89 settings in 8 categories. A flat list would be
several screens of scrolling and the old 8-tab strip did not scale. The index is the map;
the category page is the room.

3) REMOVED / DE-DUPLICATED
  - "Make YouTube Playlists Local" (YouTube tab): duplicate of Library > Imports > YouTube.
  - "Your Spotify Playlists" (Spotify tab): duplicate of Library > Imports > Spotify / Apple Music.
  - "Import from YouTube Music" (YouTube tab): duplicate of Library > Imports.
  - Standalone "Download Desktop App" row in About: duplicate of the button inside the About card.
  - "Lyrics Animation Style" search entry: never existed in the UI (phantom catalog entry).
  - The old search entry appearance.home_sections pointed at Appearance; it now points at
    Library / Home, where Home Sections has always lived.
  - YouTubeImportSheet.kt (370 lines): never made visible; deleted.
  - Jam bottom sheet state: never made visible; deleted (the Jam screen is unchanged).
  - YouTube "Two-way Playlist Sync" row is now hidden while disconnected. It used to render as a
    toggle that always looked off but still changed the setting.

4) SEARCH INDEX FIXES
  - Search catalog rewritten: 89 entries covering every searchable setting.
  - Every catalog section must exist in SettingsTab.sectionOrder; a unit test now enforces it.
  - Search scrolls by section index derived from that one order list, not hard-coded indices.
  - Added entries that existed in the UI but were unsearchable, e.g.:
      Music Haptics, Hide Navigation Tabs, Collapsing Navigation Bar, Button Now Playing,
      Word-by-Word Lyrics, Show AutoEQ in Volume Panel, Spotify Playlists in Library,
      YouTube Cookie Login, LastWave Jam, Downloads/Storage.
  - Removed phantom/duplicate entries: Lyrics Animation Style (phantom), duplicate YouTube/Spotify
    import entries. The old appearance.home_sections entry was repointed to library.home_sections.

5) KNOWN GAPS (not changed by this PR)
  - Download folder / location / structure still live in the Downloads screen overflow menu.
    Settings > Downloads links to that screen.
  - preferLosslessStreaming and clarityPreset/clarityAtmosBypass still have no UI.
  - Tablet content width is not capped (fillMaxSize before adaptiveContentWidth); a two-pane
    tablet settings layout is the right follow-up.
  - Section labels are still English-only; category titles use string resources.
  - The shared search catalog stores static descriptions, not live values.
