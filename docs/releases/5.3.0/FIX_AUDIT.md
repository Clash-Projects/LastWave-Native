# LastWave 5.3.0 — fixes and performance audit

Scope: merged pull requests and feature-branch integrations after published **5.2.1** (`6db7b99bb2fdeb052f59e3cc1a5e284feac43ee0`), checked against main at **`75e6bdcb8a5fc3d8898f6d26ae58728d8c104223`**, November 24, 2026. This is a grouped release inventory, not an individual commit chronology. Earlier 5.2.0/5.2.1 fixes are excluded. Authors below are the contributors who authored the PRs or integrated branches, rather than the person who clicked Merge.

## Claims to exclude or qualify

- **“More than 50 GitHub issues fixed” is not established by this merged-PR inventory.** PRs, individual commits and fixed issues are different counts; some PRs are features, release preparation, or repeated polish. Use “multiple fixes across playback, lyrics, the library and audio” unless an issue-by-issue tally is supplied.
- **Do not repeat the 59-second stream/download, FLAC seeking, local scan-scope or earlier 5.2.1 fixes.** Those were already in the baseline release. The new synced-video alignment fetch correction is narrower: it uses the shared 512 KB range size.
- **[#642](https://github.com/Clash-Projects/LastWave-Native/pull/642)'s existing-playlist chooser fix was reverted.** Later integrated library code changes remote adding and per-playlist failure handling, but the original chooser-filter fix is not retained; do not advertise that original PR as resolved.
- **The EQ soft-limiter change was reverted.** Do not claim reduced clipping, a new transparent limiter or improved loudness from that proposed change.
- **[#459](https://github.com/Clash-Projects/LastWave-Native/pull/459)'s addon-token exclusion was superseded by [#691](https://github.com/Clash-Projects/LastWave-Native/pull/691).** The final snapshot exporter includes all string preferences. Do not advertise token exclusion or backup security hardening.
- **[#699](https://github.com/Clash-Projects/LastWave-Native/pull/699)'s header recognition-button restoration was superseded by [#741](https://github.com/Clash-Projects/LastWave-Native/pull/741).** Final recognition entry is Search.
- **[#717](https://github.com/Clash-Projects/LastWave-Native/pull/717)'s non-glass mini-player progress addition was removed by [#741](https://github.com/Clash-Projects/LastWave-Native/pull/741).** AutoEQ import/export and text-input additions remain, but “progress restored with Liquid Glass disabled” is not the final behavior.
- **The unavailable-section placeholder from [#643](https://github.com/Clash-Projects/LastWave-Native/pull/643) was removed in later feed work.** Describe progressive loading and stable/paged sections; do not describe the abandoned stale-content placeholder.
- **Whole-song AutoMix preview decoding was removed before [#706](https://github.com/Clash-Projects/LastWave-Native/pull/706) merged.** Final preview shows the transition cue window with context on both sides, not a full-song waveform.
- Build/import repairs, duplicate intermediate patches and dependency/license updates are maintenance, not separate user-facing fixes. The direct-main Discord presence change is outside this strictly merged-PR/branch inventory.
